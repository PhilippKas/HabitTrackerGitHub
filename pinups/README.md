# Pin-up images

The app uses these images in the pin-up corner when this folder is present.
Tap a slot to cycle the built-in drawings; drop your own images here
(`pinup-1.png/jpg/webp`, `pinup-2…`, `pinup-3…`) to replace them.

Current images (all public domain, via Wikimedia Commons):

1. `pinup-1.jpg` — *Gibson Girl*, Charles Dana Gibson, c. 1891
   https://commons.wikimedia.org/wiki/File:Gibson_Girl_by_Charles_Dana_Gibson.jpg
2. `pinup-2.jpg` — *Pearl Germond*, Alfred Cheney Johnston, 1920
   https://commons.wikimedia.org/wiki/File:Pearl_Germond_1920.png
3. `pinup-3.jpg` — *Olive Brady*, Alfred Cheney Johnston, 1928
